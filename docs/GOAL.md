# GOAL — 静默剧透保护

目标：YouTube 评论区静默、可撤销、如实表达覆盖范围。黑兜帽 Veil Keeper 承担品牌和状态，不做聊天助手。

## 当前验收标准

1. 待判断先遮、失败继续遮、可主动揭开。不得承诺网络必定 1 秒返回。
2. 翻译、点赞、回复不与遮罩重叠；短/长评论、Cover/Collapse、深浅主题都验证。
3. 揭开保留 24px Keeper；单条和批量再次遮盖可用。
4. toolbar / player / popup 共用角色状态协议，不用数字或 ✓ ! × 作为主状态。
5. 无限加载、回复、编辑、DOM 回收、SPA、迟到响应及多标签页不串状态。
6. 设置即时生效；敏感度复用概率，观看作品变化重判。
7. 判断有预算、合并、缓存、部分失败、有限重试和旧 Worker 兼容，长评论不截断。
8. compile、tests、Worker tests、build/zip 通过；服务部署独立记录。
9. v2 规则重跑五类真实视频，不把 v1 手测当成当前验收。
10. 文档、商店图与实际界面一致后再提交。

仅实现 YouTube 评论；Bilibili 评论/弹幕和日本弹幕站留解耦接口。本轮无付费、账号、自定义规则 UI、标题/缩略图屏蔽、Firefox 专项验收。部署、提交与营销是独立动作。
