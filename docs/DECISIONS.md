# DECISIONS（append-only）

## 2026-09-20 · 名字 PlotVeil

plot 剧情、veil 遮罩，合起来就是产品做的事，泛化时去掉 plot 只剩 Veil 也成立。
X 上无同名、Google 无精确匹配。备选 SpoilerVeil 更占商店搜索便宜但锁死在剧透，放弃。
域名不做 SEO 依赖，便宜后缀即可，plotveil.io 查到可注册。

## 2026-09-20 · 只做评论区，不做标题和缩略图

SpoilerCub 等关键词产品的主功能是遮视频标题和缩略图，那是关键词能胜任的场景。
我们的差异只在「没有关键词的剧透评论」，把全部力气放在这一处。

## 2026-09-20 · Jev 直连 TypeSafe，Workers AI 备选

最初打算走 Workers AI 免 waitlist，但主人当天已拿到 TypeSafe key，直连价格公开（$0.042/MTok 输入，输出免费）、
实测 0.7s 往返、判断准确，没有理由绕一层。Workers AI 上的 `typesafe/jev` 单价未公开，只留作备选。
密钥仍只存在 Worker secret，扩展侧无密钥。

## 2026-09-20 · 判断失败即放行

「全遮」当兜底等于关掉评论区，比剧透更让人卸载。失败放行并在 popup 说明原因。

## 2026-09-20 · 规则是数据不是代码

架构按「自然语言规则 → 每条内容 yes/no → 遮罩」设计，剧透是第一条内置规则。
MVP 不暴露自定义规则 UI，但判断层不得写死「剧透」二字在类型或函数名上。

## 2026-09-20 · 阈值默认 0.7，宁高不低

漏遮一条真剧透的代价（卸载）远高于多遮一条（点一下）。三档给用户调，默认取偏严一侧。
先调判断题措辞，再调阈值，阈值是最后一道手段。

## 2026-09-20 · 商店提交先于 PH 日期

审核 1 到 3 天不可控。周日晚提交，审核过了周二发 PH，没过顺延周四。不在周三发。

## 2026-09-20 · YouTube DOM 结构记录与元数据兜底

评论节点是 `ytd-comment-view-model`（回复同样是它，嵌在 `ytd-comment-replies-renderer` 里），正文 `#content-text`，
幕布盖在 `#expander` 上（连 Read more 一起盖，容器高度不变）。评论没有暴露稳定 id 属性（Polymer 的 `.data` 在 isolated world 拿不到），
所以 id = fnv1a(作者 + '|' + 正文)，同一视频同一评论稳定，跨会话可缓存。

视频标题与频道名优先读 DOM，读不到（自动化浏览器被 YouTube 判为机器人时整块元数据为空；合作视频的频道名带「以及另外 N 位」后缀）
就走同源 `/oembed?url=…`，免登录、不带任何身份，一个视频最多请求一次。这是 YouTube 自己的接口，不算「往 Worker 以外发数据」。

## 2026-09-20 · 隐藏的 Worker 地址覆盖项

`storage.local.proxyUrl` 存在即覆盖内置 Worker 地址，界面不暴露。用途：手测失败放行路径、以后自托管。

## 2026-09-20 · KV 配额计数是乐观写，不做原子

KV 没有原子自增，两批并发时以后写者为准，可能少计。配额是软限制（防滥用而非计费），少计对用户有利，接受。

## 2026-09-20 · 落地页与隐私页挂在 proxy Worker 的静态资源上

不另起 Pages 项目。`site/` 作为 `assets` 绑到同一个 Worker，`/judge` `/usage` `/health` 走 Worker 代码，其余走静态。
一个 deploy 命令、一个域名、以后加自定义域只改一处。落地页只有一屏加一段说明，幕布落下再拉开用 CSS 动画而非 gif。

## 2026-09-20 · Veil Keeper 替代旧图形资产

品牌视觉以黑兜帽 Veil Keeper 为唯一基准：深炭黑兜帽、暖白脸、两只竖椭圆眼睛、少量琥珀黄。旧抽象幕布 Chrome 图标与红制服领座员插画作废。
Head Mark 负责 Chrome 图标与品牌头像；完整角色固定为 Default / Guard / Peek / Safe / Warning 五态。评论遮罩只让 Peek 在右侧小面积探出，避免吉祥物抢过 YouTube 评论本身。

## 2026-09-20 · 揭开必须可逆

`Show anyway` 后保留一个 24px Head Mark；点击它重新遮盖同一评论。揭开与重新遮盖都同步更新 `storage.session` 的 revealed 集合，避免 DOM 回收、SPA 导航或刷新后状态与界面不一致。

## 2026-09-20 · 静默保护与作用域修订（取代上文对应行为）

品牌五态插画用于宣传；功能状态改为七个同源 Head Mark：neutral/scout/calm/guard/peek/concerned/closed。工具栏、播放器和 popup 共用状态协议，不加数字/符号徽标。后续批次不让已有结果反复闪动；详情明确 pending 与覆盖范围。

失败放行被先遮后判、失败保留遮罩取代，允许主动揭开。揭开只属于当前文档的视频会话，不再写共享 storage.session revealed；刷新和导航重置，同页 DOM 回收重用，不跨标签页传播。24px 再遮盖入口保留。

播放器 DOM 注入只是辅助入口；没有官方稳定插槽，不能因挂载失败中断评论保护。遮罩采用单行 Shadow DOM 布局，不覆盖翻译与操作行。小尺寸功能角色从现有 SVG 母版派生，运行时不携带大型插画和旧字体。

## 2026-09-20 · 判断核心与未来弹幕

SiteAdapter<Target> 不限定 HTMLElement，runner 注入服务且不依赖浏览器。站点负责采集、导航和呈现；判断只接收证据。scope 包含平台/内容/载体。未来优先 Bilibili 评论和弹幕、日本弹幕站；本轮不实现新站、播放时钟或 Canvas 拦截。

Jev v2 使用共享 state、逐题显式内容路径、noul 概率。缓存指纹覆盖完整证据和端点；阈值本地重算，在途合并、全局并发 2。单条 10000/每批 16000 字符预算，不截断；旧 Worker 长评论结果需 schemaVersion:2 才信任。有限过载退避取代无边界重试，KV 仍仅软额度。详见 ARCHITECTURE 与最新 QA，旧五视频 v1 结果不是本轮验收。

## 2026-09-21 · 状态母板与组件姿态分层

Guard / Concerned 的功能图标统一为头像级构图，原全身 Guard / Warning 只保留作营销插画。评论遮罩继续使用适合趴在边缘的造型，但独立命名为 Mask Perch；它从 Peek 母版派生，只是组件构图，不进入 ProtectionPhase，也不表示 revealed。Peek 状态仍只用于用户已揭开和重新遮盖入口。

## 2026-09-21 · Bilibili 定位为自用与预研，排在商店过审之后

海外市场奔着盈利，国内市场是自用和炫技——这两条线的成本约束不同，不能用同一把尺子量。
自用 N=1，判断结果没有共享对象，所以「服务端按 cid 共享缓存」整块不做；
成本也不再是约束：一集 45 分钟电视剧约 120k input tokens ≈ $0.005，一年 500 集约 15 元。
对应砍掉配额单位重构、商店、七态打磨、五类视频 QA 和 B 站评论区适配，只做弹幕。

不在发布前开工。YouTube 版离提交只有几天，而它是盈利线，启动的是「用户反馈」这个长周期变量；
B 站自用版晚两周做没有任何损失，没有竞争窗口要抢。炫技也需要先有技可炫的证据。

投入的复利在于它是日本弹幕站（niconico）的技术预研：弹幕预取、时间轴窗口、节点复用这套问题同源，
而 niconico 是海外、有付费习惯、弹幕文化更重。渲染拦截那层不能假设可迁移，需重新验证。

规格冻结在 docs/spec/BILIBILI.md，技术验证已全部完成，解冻后照办不重新调研。

## 2026-09-21 · 不做 Netflix 方向

Netflix 没有 UGC 文本，能遮的只有剧集标题、下集简介和缩略图，
而这正是 2026-09-20「只做评论区，不做标题和缩略图」已经否决过的关键词产品地盘。
把「海外市场」和「流媒体平台」分开：PlotVeil 的市场是人们看完片之后打字讨论的地方，
不是看片的地方。真要扩海外，方向是 Reddit——UGC 文本密集、剧透文化被官方 spoiler tag 承认、
与 YouTube 同构无新形态。但不在发布前做。
