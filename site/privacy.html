Privacy

To judge a comment, PlotVeil sends it.

Last updated 21 September 2026. The short version: comment text, video context and optional protected titles are sent for spoiler checks, along with an anonymous installation ID used only for the daily quota.

No analytics, no tracking pixels and no third-party scripts in the extension. This website counts page views with a self-hosted, cookieless analytics script (Umami on um.korx.cc). Fonts are served from this domain.

What PlotVeil sends

While protection is enabled, comments near the viewport are sent with the video's title, channel, any works you have chosen to protect, and an anonymous installation ID. The extension does not add your Google account, cookies, watch history, comment author name or page URL to this request. Network requests carry an IP address, and comment text itself may contain personal information.

Comments are sent in batches of up to 20, only for the video you are watching, only while PlotVeil is switched on.

What PlotVeil stores

  • On your device: settings, judgment probabilities keyed by hashed evidence in a session cache, and a random installation identifier (shown as Installation in Settings). It is not linked to a PlotVeil account.
  • In the proxy's quota store: daily counts keyed by the installation ID, expiring after 48 hours. Application code does not persist comment text in this store.

Who else sees the text

Requests pass through a Cloudflare Worker to TypeSafe's Jev API. The model receives comment text, video title, channel and optional protected titles, but not the installation ID. Cloudflare and TypeSafe operate their own infrastructure; this description does not promise retention practices beyond PlotVeil's application code.

What PlotVeil does not do

  • No analytics, no tracking pixels and no third-party scripts in the extension itself.
  • No reading of any page other than youtube.com.
  • No sale of comment text or use for unrelated advertising in PlotVeil's application.

This website

Page views on plotveil.app are counted by Umami, a self-hosted analytics service running on um.korx.cc. It sets no cookies, stores no personal data and builds no cross-site profile; what is recorded is the page, referrer, and coarse browser, device and country information derived from the request. This applies to the website only — the extension sends nothing to it.

Permissions

storage for your settings, and access to youtube.com so the extension can read comments on the page you are on. Nothing else.
